# Agentic Website Studio contributor rules

- Build a model/provider-agnostic, evidence-first workflow. Never present inference as observation.
- References inform abstract principles; cloning or reusing original assets is not the default.
- Public access is not reuse permission. Preserve rights metadata and provenance in artifacts.
- Versioned schemas and generated artifacts are the source of truth, not chat history.
- Validate deterministic properties in code. Future builders must receive independent audit and human creative/release review.
- Work only inside this repository. Use project-local dependencies; no global installs, Docker, GitHub Actions, or Computer Use.
- Browser automation is allowed, but authenticated/private-source scraping is not.
- Run `npm run check` locally. Generated evidence, browser binaries, caches, and `node_modules` stay uncommitted.
